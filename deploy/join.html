Join with MCPersist

The server you tried to join requires the free MCPersist mod. Setting it up takes about five minutes.

  1. Get a modded Minecraft

    Install a launcher that handles mods for you, like the Modrinth App, Prism Launcher or the CurseForge app.

    Create a new profile for the server's Minecraft version (for example 26.3) with Fabric, NeoForge or Forge. Any of the three works.

  2. Add the mods

    MCPersist: download the jar for your loader from the latest release and add it to the profile's mods. On Fabric, also add Fabric API.

    If the server also asks for Simple Voice Chat, add Simple Voice Chat for your loader too.

    In a launcher, "Add mods" or "Add file" puts a downloaded jar in the right place.

  3. Join

    Start the profile, open Multiplayer, click Add Server and enter the server's address again.

The official server

Address official.mcpersist.com: Minecraft 26.3, with MCPersist and Simple Voice Chat. Claim land with diamonds, team up, and raid rival teams in declared wars.

What is MCPersist?

A mod that puts your own singleplayer world online with no port forwarding, and keeps it running after you leave. Learn more.
